INVESTIGACIÓN

JSON

Formato utilizado para almacenar y transportar información de manera sencilla.

¿Qué es JSON?

JSON significa JavaScript Object Notation. Es un formato ligero utilizado para representar y transmitir datos. Es muy utilizado en aplicaciones web y APIs.

Clave y valor

JSON organiza la información utilizando pares de clave y valor. 


{
    "nombre": "Sudadera Oversize",
    "precio": 25,
    "color": "Negro"
}

Objetos y arreglos

Objeto


{
    "nombre": "Camiseta",
    "precio": 15
}

Arreglo


[
    "Camiseta",
    "Sudadera",
    "Pantalón"
]

Objeto JavaScript vs JSON

Objeto JavaScript


const producto = {
    nombre: "Hoodie",
    precio: 28
};

JSON


{
    "nombre": "Hoodie",
    "precio": 28
}

JSON en Urban Style

En este proyecto utilizamos un archivo productos.json para guardar la información de los productos.

JavaScript obtiene esa información y la muestra automáticamente en la página de productos.

JSON y servidores

JSON es muy utilizado para intercambiar información entre páginas web, servidores y APIs.
