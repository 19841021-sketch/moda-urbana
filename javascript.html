INVESTIGACIÓN

JavaScript

El lenguaje que permite agregar interactividad y comportamiento dinámico a una página web.

¿Qué es JavaScript?

JavaScript es un lenguaje de programación utilizado principalmente para crear páginas web interactivas. Permite modificar elementos de una página, responder a acciones del usuario y realizar diferentes procesos.

HTML, CSS y JavaScript

HTML

Define la estructura y el contenido de la página.

CSS

Define los colores, tamaños, posiciones y diseño.

JavaScript

Agrega comportamiento e interactividad.

Variables

Las variables permiten guardar información que puede utilizarse durante la ejecución de un programa. 


let nombre = "Urban Style";
let precio = 25;
let disponible = true;

Funciones

Una función es un bloque de código que realiza una tarea específica y puede ejecutarse cuando sea necesario. 


function mostrarProducto() {
    alert("Producto seleccionado");
}

Eventos

Los eventos permiten que JavaScript responda a acciones realizadas por el usuario, como hacer clic, escribir o mover el mouse. 


document.getElementById("boton")
.addEventListener("click", function() {
    alert("Haz hecho clic");
});

Uso de JavaScript en Urban Style

En este proyecto JavaScript se utiliza para cargar productos desde un archivo JSON, mostrar información dinámicamente y crear interacciones dentro del sitio.
