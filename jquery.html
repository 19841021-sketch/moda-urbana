jQuery

Una biblioteca de JavaScript creada para facilitar la manipulación de páginas web.

¿Qué es jQuery?

jQuery es una biblioteca de JavaScript que fue creada para simplificar tareas comunes como seleccionar elementos, modificar contenido, manejar eventos y crear efectos.

¿Por qué fue creado?

Fue creado para hacer más sencilla la programación de páginas web y reducir la cantidad de código necesario para realizar algunas tareas con JavaScript.

La sintaxis $

Una de las características más conocidas de jQuery es el uso del símbolo $ para acceder a elementos y funciones de la biblioteca. 


$("#boton").click(function() {
    alert("Producto seleccionado");
});

JavaScript moderno vs jQuery

JavaScript moderno

No necesita una biblioteca externa para muchas tareas comunes.

jQuery

Simplifica algunas operaciones mediante métodos y una sintaxis más corta.

Efectos de jQuery

jQuery permite crear efectos visuales como fadeIn(), fadeOut() y slideToggle().
